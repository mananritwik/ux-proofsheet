# Prompt cookbook

Paste-ready prompts for Mobbin + Figma users. Pick one; swap the URL / competitors.

## One screen (Full)

```
Review this Figma home screen against Jobber and Housecall Pro (plus 2–3
cross-industry analogues): https://figma.com/design/FILE/Name?node-id=1-2
Full proofsheet please.
```

## One screen (Quick)

```
Quick proofsheet on this frame only — top findings + scorecard + a few
Mobbin backs. Competitors: Stripe, Square.
https://figma.com/design/FILE/Name?node-id=1-2
```

## Multi-screen

```
Competitive review of these three screens (home, menu, profile) in
https://figma.com/design/FILE/Name?node-id=1-2 — cover all three, Full mode.
We compete with [A] and [B].
```

## “Is this conventional?”

```
Is a bottom-sheet workspace switcher conventional for B2B SaaS, or are we
doing something weird? Here’s the frame: [Figma URL]. Show same-industry and
cross-industry examples.
```

## Named pattern hunt

```
Find how other fintech apps show “money owed” on home so I can compare mine.
My design: [Figma URL or screenshot]. Include Afterpay / Revolut if they’re
in Mobbin.
```

## Follow-ups (after a report)

```
Dig into N1 — more Mobbin evidence and a sharper fix.
Only compare to Jobber for the nav findings.
Re-run the UX copy dimension with a side-by-side matrix.
Quick mode on just the empty state.
```
